# 🕶️ ZeroTrace Planner — ანონიმური ყოველდღიური დამგეგმავი

ვებ-აპლიკაცია ყოველდღიური დავალებების სამართავად, სადაც მთავარი პრიორიტეტია **აბსოლუტური კონფიდენციალურობა და ანონიმურობა**. პროექტი არ იყენებს სერვერებსა და მონაცემთა ბაზებს — შენი გეგმები ინახება მხოლოდ შენს ბრაუზერში.

## 🚀 ძირითადი ფუნქციონალი
* **დავალებების დამატება და მართვა:** მიმდინარე დღის გეგმების სწრაფი შექმნა და დასრულებულად მონიშვნა.
* **პროგრესის ტრეკერი:** დღევანდელი შესრულებული დავალებების პროცენტული მაჩვენებლის ავტომატური გამოთვლა რეალურ დროში.
* **სრული ანონიმურობა:** ბექენდის არარსებობის გამო, მონაცემები ინახება ადგილობრივად (`localStorage`-ით) და იშლება ბრაუზერის ისტორიის გასუფთავებისას. არავინ იცის, რას გეგმავდი აქამდე.
* **რესპონსივული დიზაინი:** იდეალურად მუშაობს სმარტფონებზე, პლანშეტებსა და კომპიუტერებზე.
